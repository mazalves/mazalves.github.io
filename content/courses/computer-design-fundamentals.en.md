## Suggested syllabus

- Introduction, digital signals, and signal discretization
- Number systems, bases, and base conversion
- Basic binary arithmetic: addition, subtraction, and multiplication
- Boolean algebra, truth tables, and algebraic properties
- Karnaugh maps and don't-care bits
- CMOS transistor implementation and resulting delays
- Logic gates and mapping functions to circuits
- Basic combinational blocks: adders and subtractors
- Combinational blocks: decoders and multiplexers
- Waveforms, signal propagation, and contamination delays
- Sequential circuits: SR, RS, and D latches
- Sequential circuits: latches, flip-flops, and memories
- Finite-state machine design
- Combinational and sequential circuit design
- MIPS: instruction set, ALU and memory instructions
- MIPS: control-flow instructions and iteration
- Single-cycle MIPS: datapath
- Single-cycle MIPS: control unit
- MIPS pipeline: datapath and control
- MIPS pipeline: data dependencies
- MIPS pipeline: control dependencies
- Flynn's taxonomy and processors
- Multithreading
- Cache memory I
- Cache memory II
- Virtual memory
