## Suggested syllabus: Advanced Computer Architectures

- MIPS review: pipeline
- MIPS review: data and control dependencies
- Fetch stage: block size, fetch buffer, trace cache
- Decode stage: micro-operations, decode buffer, decoded cache
- Branch prediction I: predication, branch target buffer, call/return stack
- Branch prediction II: direction prediction (static, 1-bit, 2-bit, two-level, global/local signatures)
- Precise exceptions and interrupts: reorder buffer, history buffer, future register file, checkpointing
- Rename, dispatch, execute, and commit: scoreboard, Tomasulo, centralized/distributed reservation stations
- Caches I: associativity, line size, hierarchy
- Caches II: replacement policies, parallel/sequential lookup
- Caches III: multi-port, multi-banked, non-blocking caches
- Software prefetching
- Hardware prefetching
- Multithreading and multicore
- Networks-on-Chip (NoC): topologies and routing
- Memory Management Unit (MMU): Translation Lookaside Buffer
- MMU: paging and caches
- Memory controllers and DDR memories
- Hybrid Memory Cube (HMC) and High Bandwidth Memory (HBM)
