## Suggested syllabus: Computer Architecture

- Course introduction
- Single-cycle MIPS: datapath
- Single-cycle MIPS: control unit
- ISA characteristics and RISC processors
- Multi-cycle MIPS: datapath
- Multi-cycle MIPS: control unit (FSM overview and control signals)
- Multi-cycle MIPS: FSM and microprogramming
- Performance analysis
- MIPS pipeline: datapath and control
- Pipeline data dependencies
- Pipeline control dependencies
- Binary arithmetic: integers and floating point
- Specialized pipelines and precise exceptions
- Superscalar processors and out-of-order execution
- VLIW processors
- Flynn's taxonomy
- Multithreaded processors
- Cache memory I
- Cache memory II
- Interconnections
- Virtual memory I
- Virtual memory II
- DDR, intelligent memories, and 3D stacking
